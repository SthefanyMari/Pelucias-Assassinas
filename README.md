## Origem dos códigos

O projeto foi desenvolvido, com auxílio do ChatGPT,da OpenAI, na elaboração,
explicação e adaptação de trechos de GDScript.
A assistência foi utilizada na perseguição e navegação dos inimigos, ataques, poderes, 
sprites e controle da partida.

Ferramenta: ChatGPT — OpenAI.
Link: https://chatgpt.com/

## Origem das artes

Os sprites e tiles gerados para o projeto foram produzidos com auxílio
de geração de imagens por IA no ChatGPT, a partir das minhas solicitações.

Origem: geração por IA — ChatGPT/OpenAI.
Link: https://chatgpt.com/
